# 🔐 CyberSentinel

**AI-Powered Cybersecurity Intelligence Platform**

CyberSentinel is an offline-first Android application designed to detect phishing attempts and identify unusual cybersecurity activities using machine learning.

## Core Modules

### PhishNet
- URL phishing detection
- Email threat classification
- Risk scoring and explanations

### ThreatLens
- Security log analysis
- Anomaly detection
- Incident summaries

## Technology Stack
- Flutter & Dart
- Python
- Machine Learning
- TensorFlow Lite
- SQLite

## Project Status
Planning and architecture documentation completed.

## Project Vision
To build an intelligent, explainable and privacy-conscious cybersecurity application with on-device analysis capabilities.
