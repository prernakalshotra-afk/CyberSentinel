# CyberSentinel

## AI-Powered Cybersecurity Intelligence Platform

### Project Overview
CyberSentinel is an AI-powered Android application designed to identify potential phishing threats and analyze suspicious cybersecurity events.

### Core Modules

#### 1. PhishNet
- URL phishing detection
- Email threat classification
- Risk scoring
- Explainable detection results
- Scan history

#### 2. ThreatLens
- Security log analysis
- Anomaly detection
- Suspicious event classification
- Threat correlation
- Incident reporting

### Technology Stack
- Frontend: Flutter and Dart
- Machine Learning: Python
- Model Deployment: TensorFlow Lite
- Local Database: SQLite
- Development Environment: Visual Studio Code

### Project Goals
- Build an offline-first Android application.
- Develop and evaluate our own machine learning models.
- Provide understandable security alerts.
- Generate an installable Android APK.

### Development Approach
The project will be developed in stages: UI development, dataset preparation, model training, model integration, testing and APK generation.
